# Háromprojektes integrációs pilot

## 1. Előkészítés alatt álló családi ház

Contract Generator → CRM → PM Cockpit → Smart Calendar → Finance → MyImperial.

Ellenőrzés: szerződéses bevétel, számlázási pont hash, ügyféldöntési státusz.

## 2. Aktív kivitelezés és beszerzés

Procurement → Finance → Smart Calendar → PM Cockpit.

Ellenőrzés: rendelési kötelezettség, átvett/számlázott mennyiség, hiányzó szállítólevél, outbox-továbbítás.

## 3. Változtatás és garancia

ChangeControl → Finance → Imperial Care → PM Cockpit.

Ellenőrzés: jóváhagyott pótmunka pénzügyi átvezetése, eltérés felismerése és feloldása, garanciális vezetői kivétel.

A beépített pilot szintetikus. Az éles pilothoz három valódi ProjectID, tényleges felelősök, modul URL-ek, szolgáltatáshitelesítés és jóváhagyott adatkezelési szabály szükséges.
