# Védett acceptance/regression corpus

Ez a mappa azokat az aranyteszteket és üzleti példákat tartalmazza, amelyekhez a fejlesztő agent nem igazíthatja hozzá észrevétlenül a tesztet. A fájlok SHA-256 hash-e a `protected-corpus-manifest.json` állományban szerepel. Módosításuk R3 kockázatú, külön review- és owner gate-köteles változtatás.
